# ChatGPT Project Loader V2

Use this shared bootstrap on fresh entry, reentry, a new objective, a durable result, STOP recovery, or a cross-role handoff. Read the selected Project Instructions for `PROJECT_ROLE`, `REPO_FULL_NAME`, `INSTRUCTION_REF`, and the connected GitHub Connector.

- Stop with `PROJECT_ROLE_REQUIRED / STOP` if `PROJECT_ROLE` is missing, a placeholder, or not `Dispatcher` or `Architect`. Stop with `PROJECT_BINDING_REQUIRED / STOP` if `REPO_FULL_NAME` or `INSTRUCTION_REF` is missing or a placeholder. `INSTRUCTION_REF` is a branch used only to locate trusted instructions; it is not a Working Issue or task authorization.
- Use the Connector to resolve `REPO_FULL_NAME`; confirm the returned repository full name exactly matches it. Resolve `INSTRUCTION_REF` only as a named branch in that same repository, and confirm the branch exists. Do not substitute a default branch, arbitrary commit, Starter, parent repository, or `upstream`.
- Inspect the effective branch protection or ruleset for that exact branch. Confirm active, enforceable protection applies to the named branch. If the branch is missing, unprotected, protection is inactive, or the Connector cannot establish effective coverage, stop with `INSTRUCTION_PROTECTION_REQUIRED / STOP`. Do not infer protection from the branch name alone.
- Resolve the protected branch head to one immutable commit SHA. Fetch every required instruction from `REPO_FULL_NAME` at that exact SHA. If the branch moves during loading, restart against one newly verified SHA; never mix refs or read a moving branch after resolving the SHA.
- At that repository and SHA, fetch and verify this Loader, root `AGENTS.md`, and only the selected Guide: `Dispatcher` -> `docs/mission-control/dispatcher-guide.md`; `Architect` -> `docs/mission-control/architect-guide.md`.
- Stop with `REPOSITORY_AUTHORITY_MISMATCH / STOP` if repository identity, branch, effective protection, SHA, Loader, root `AGENTS.md`, or selected Guide is missing or inconsistent. Name the failed check. Never use cached text, an unmerged candidate, a fork's parent, or the other role's Guide as a fallback.

Follow only the selected Guide for role behavior and user-led Working Issue discovery. The instruction branch supplies policy text only; it does not select a task, grant Source authority, or authorize GitHub mutations. Verify task-specific authority from live GitHub evidence after the user identifies a task. A GitHub comment records a handoff; it does not launch a ChatGPT or Codex session.
